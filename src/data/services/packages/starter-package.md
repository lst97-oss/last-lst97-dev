# What is included in the Starter website package?

- **Topic:** Packages and Pricing
- **Source ID:** starter-package
- **URL:** https://www.lst97.dev/services

This document describes the Website Packages offering: a new website built from scratch. It covers the Starter package only, and it does not cover the Go Support Plan, which is a separate service for a website or application that already exists and is priced on a different scale. A visitor asking for help with an existing site needs the Go Support Plan, not this package.

The Starter package costs from A$1,000. It is a streamlined website for businesses that need a professional online presence without complex content management or integrations.

Everything in the Starter package is included in the work:

- Up to 5 standard pages
- Responsive desktop, tablet and mobile development
- Homepage
- About page
- Services or information pages
- Contact page
- Contact form
- Basic technical SEO
- Metadata configuration
- Sitemap
- robots.txt
- Production deployment
- Domain configuration assistance
- Responsive and browser testing
- Two revision rounds

The Starter package is suitable for small businesses, trades and service providers, personal brands, portfolio websites, and simple company websites.

The Starter package deliberately has no content management system, so adding a blog, an editable CMS, email integration, or analytics moves the project to the Business package, which starts from A$2,200. Additional pages, advanced forms, custom animations, third-party integrations, and further revision rounds are available as paid add-ons on top of any package.

The A$1,000 figure is a starting price for building a new website. It is not a support rate, and it is not the fee for fixing or deploying an application that already exists.
