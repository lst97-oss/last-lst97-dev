# What technology is used, and what costs extra?

- **Topic:** Process and Technology
- **Source ID:** technology-and-third-party-costs
- **URL:** https://www.lst97.dev/services

This document describes the Website Packages offering: a new website built from scratch. It covers the technology stack chosen for a new build and the third-party costs that sit outside a package price. It does not cover the Go Support Plan, which is a separate service for a website or application that already exists and is priced on a different scale. The stack a client's existing application already uses is inspected during support, not chosen here.

Technology is selected according to the requirements of each project, so the exact stack may vary between projects. A typical project may use React, Next.js, TanStack Start, TypeScript, Tailwind CSS, headless CMS platforms, Cloudflare, Vercel, Resend, Google Analytics, and Cloudflare Analytics.

The objective of the technology choice is always the same: to provide a website that is fast, responsive, secure, maintainable, search-engine friendly, easy to manage, and ready for future development.

Third-party service costs are separate from the website development fee. Unless specifically included in the quotation, these are not covered by the package price. They may include:

- Domain registration
- Website hosting
- CMS subscription fees
- Email service fees
- External API charges
- Premium plugins
- Premium themes
- Premium components
- Licensed fonts
- Stock photography
- Paid analytics services
- Other subscription-based services

Where appropriate, free service tiers can be used for smaller websites. Any expected recurring costs are discussed with the client before implementation begins.

These third-party charges are billed by the provider, not by Nelson, and the same rule applies under the Go Support Plan: a standard support engagement configures the database or hosting that an application uses but does not pay that provider's bill.
