# What is included in the Business+ website package?

- **Topic:** Packages and Pricing
- **Source ID:** business-plus-package
- **URL:** https://www.lst97.dev/services

This document describes the Website Packages offering: a new website built from scratch. It covers the Business+ package only, and it does not cover the Go Support Plan, which is a separate service for a website or application that already exists and is priced on a different scale. A visitor asking for help with an existing site needs the Go Support Plan, not this package.

The Business+ package costs from A$3,500. It is for businesses requiring a more customised website, additional functionality, or advanced content management.

Everything in the Business package is included in Business+, which is priced from A$2,200 and covers a complete business website with a headless CMS, a blog system with a listing page and individual article pages, CMS content modelling, contact and transactional email integration, basic structured data, enhanced technical SEO, analytics integration, social sharing metadata, a content management interface, production environment configuration, and two revision rounds. Business+ also inherits the full Starter foundation of up to 5 standard pages, responsive development across desktop, tablet and mobile, a contact form, basic technical SEO, metadata configuration, a sitemap, robots.txt, production deployment, domain configuration assistance, and responsive and browser testing.

On top of that foundation, Business+ provides additional scope for:

- Advanced custom UI
- Additional pages
- Custom animations and interactions
- Advanced CMS structures
- Multiple content types
- Third-party service integrations
- API integrations
- Advanced forms
- Dynamic website sections
- Custom business logic
- More complex deployment requirements

Final pricing for a Business+ project is provided after the complete project requirements have been confirmed, because advanced functionality and integrations vary substantially between projects.

Business+ suits businesses requiring a more customised website, additional functionality, or advanced content management. Projects that go further still — e-commerce, booking systems, customer portals, payment functionality, authentication systems, custom dashboards, CRM integrations, or business automation — are quoted separately as additional development rather than as part of the package.

The A$3,500 figure is a starting price for building a new website. It is not a support rate, and it is not the fee for fixing, improving, or deploying an application that already exists.
