# What add-ons are available, and what do they cost?

- **Topic:** Add-ons and Extras
- **Source ID:** add-ons
- **URL:** https://www.lst97.dev/services

This document describes the Website Packages offering: a new website built from scratch. Add-ons are extras added to a Starter, Business, or Business+ package. It does not cover the Go Support Plan offering, which is a separate service for a website or application that already exists and is priced on a different scale, so a figure on this page must not be quoted as the cost of supporting an existing site.

- Additional standard page — From A$100
- Advanced contact or enquiry form — From A$200
- Additional CMS content type — From A$150
- Custom animation or interaction — From A$200
- Third-party API integration — From A$300
- Content migration — Quoted based on scope
- Additional revision round — From A$100
- Ongoing maintenance — From A$50/hour

These prices are indicative starting points. Complex requirements may require a separate quotation, and a larger content migration in particular is always quoted based on its scope.

Note that the "Additional revision round — From A$100" add-on and the A$50/hour ongoing maintenance rate belong to new website builds. They are not the same as the Go Support Plan's standard support engagement, which is a different service with its own fixed scope.

Ongoing maintenance is an add-on that is arranged separately from the initial website development fee. It is not automatically included in the build price. The final maintenance plan depends on the level of support required.

Any requirement outside the agreed project scope is quoted and agreed before the additional work begins, so the total cost is never changed mid-project without approval.
