# What is not included, and how do I request a quote?

- **Topic:** Terms, Content and Quotes
- **Source ID:** terms-and-quote-request
- **URL:** https://www.lst97.dev/services

This document describes the Website Packages offering: a new website built from scratch. It covers what a package price excludes, who supplies the content, how revisions are handled, and how to request a fixed-price quotation for a new build. It does not cover the Go Support Plan, which is a separate service for a website or application that already exists and is priced on a different scale.

One figure in this document needs care because it is shared with the other offering: the additional revision round is priced from A$100, and that is a Website Packages add-on. It is a different thing from the Go Support Plan's standard A$100 engagement, which is a fixed-scope fix to an existing application rather than a build extra. A visitor asking about supporting an existing site should be given the Go Support Plan, not this add-on.

## What is not included

Unless specifically stated in the quotation, the following are not included in the standard development fee: domain purchase, hosting subscriptions, paid CMS subscriptions, paid third-party services, professional copywriting, professional photography, logo design, full branding design, legal advice, Privacy Policy drafting, Terms and Conditions drafting, large-scale content migration, e-commerce functionality, authentication systems, custom backend systems, ongoing content management, and ongoing maintenance. These services can be discussed or quoted separately where applicable.

Advanced animations, additional pages, additional CMS functionality, new integrations, new API requirements, authentication systems, customer portals, payment functionality, booking systems, e-commerce functionality, CRM integrations, search functionality, advanced CMS workflows, custom dashboards, business automation, and internal administration tools are all quoted separately and approved before the additional work begins.

## Client content responsibilities

Unless otherwise included in the agreed project scope, the client is responsible for supplying the final website content. This may include business information, written copy, images, logos, branding assets, service descriptions, contact information, product or service information, a Privacy Policy, Terms and Conditions, and other legal documentation. Content writing, editing, migration, or preparation can be quoted separately where required.

## Revisions

Every standard website package includes two revision rounds. A revision round consists of a consolidated set of reasonable changes submitted after reviewing the current project version. Revisions may include text changes, image replacements, minor layout adjustments, colour adjustments, spacing changes, and small user interface refinements. Major changes such as new functionality, significant redesigns, additional sections, or changes to the original project requirements are treated as additional work. An additional revision round is available from A$100.

## Scope changes

The quotation is based on the requirements agreed before development begins. If additional requirements are introduced during development, they are reviewed before implementation. Any additional cost is communicated and agreed before the additional work begins.

## Ongoing support

Ongoing website support and maintenance can be arranged separately after launch, from A$50/hour. Maintenance services may include dependency updates, security updates, website monitoring, content changes, minor bug fixes, performance improvements, hosting support, deployment assistance, technical support, and small feature improvements. Ongoing maintenance is not automatically included in the initial website development fee unless specifically stated in the quotation, and the final maintenance plan depends on the level of support required.

## Project handover

At the completion of the project, the client receives the agreed website and access to the relevant production services. Where applicable, handover may include the website production deployment, CMS access, hosting access, domain configuration information, basic CMS usage guidance, repository or source-code access, and environment configuration guidance. The exact handover process depends on the selected technology and hosting arrangement.

## Where services are offered

Services are currently offered in Australia, with all prices in Australian dollars (A$). Remote work for clients outside Australia is planned and will expand in the future — contact me to discuss your location and requirements.

## How to request a quote

Every website has different requirements, so an accurate quotation needs the project details. To request a fixed-price quotation, provide the business or project name, the existing website if applicable, the required pages, the required functionality, the CMS requirements, examples of websites you like, branding or design references, the required integrations, whether existing content is available, and the target launch timeframe.

Once the requirements are confirmed, a project scope and fixed-price quotation can be prepared before development begins.

## Requesting a quotation through the chat assistant

A quotation can also be requested through this site's chat assistant. Asking the assistant for a quote opens the same confirmed contact workflow used for email, bug reports, and feature requests, where the visitor selects the Quotation option and completes a structured request.

That structured request asks for exactly the details listed above — the business or project name, the existing website if applicable, the required pages, the required functionality, the CMS requirements, design references, the required integrations, content availability, and the target launch timeframe — so the project scope and fixed-price quotation can be prepared before development begins. Publishing a price, promising a timeline, or stating that a quotation is ready does not happen during the request itself; the quotation is prepared after the requirements are reviewed.
