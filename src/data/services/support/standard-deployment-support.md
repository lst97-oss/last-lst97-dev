# What is included in standard deployment support?

- **Topic:** Support Engagements
- **Source ID:** standard-deployment-support
- **URL:** https://www.lst97.dev/services

This document describes the Go Support Plan offering: technical help for a website or application that already exists. It covers the Deployment / Deployment Fix engagement. It does not cover the Website Packages offering, which builds a new website from scratch; production deployment is included in every website package rather than quoted as a support engagement.

Deployment / Deployment Fix is a standard A$100 engagement. It applies to existing websites or applications that are already functioning and mainly require production deployment or configuration.

Typical work includes:

- Vercel deployment
- Cloudflare deployment
- Netlify deployment
- Railway deployment
- Render deployment
- VPS deployment
- GitHub repository connection
- build configuration
- environment variable configuration
- production secrets
- domain connection
- DNS configuration
- SSL setup
- basic production testing

Standard deployment pricing assumes the application is already reasonably production-ready. If significant code changes, a database migration, a framework migration, or infrastructure changes are required, a separate quote is provided.

The platform list is not a restriction. The deployment target is chosen to suit the application rather than the other way around: a static marketing site and a long-running server application have different sensible homes, and the consultation stage is where that decision is made.

Basic production testing is included so that the handover verifies the application actually runs on its public origin rather than only in the local development environment. A deployment that completes without error but fails to serve a request is not a completed deployment.
