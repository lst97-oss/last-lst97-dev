# What is the Go Support Plan?

- **Topic:** Overview
- **Source ID:** go-support-plan
- **URL:** https://www.lst97.dev/services

This document describes the Go Support Plan offering: technical help for a website or application that already exists. It covers what the plan is, who it is for, and how its prices are structured. It does not cover the Website Packages offering, which builds a new website from scratch starting from A$1,000. A visitor asking for a new website needs a package, not this plan.

The Go Support Plan provides affordable technical help for websites and web applications that already exist. It is designed for businesses, founders, and individuals who already have a website or application but need help fixing, improving, or deploying it.

This service is especially suitable for projects created using AI-assisted development tools such as Cursor, Claude Code, Lovable, Bolt, Replit, v0, GitHub Copilot, and similar platforms. The plan does not build a new website from scratch; it works on an existing application that needs to become correct, secure, and live.

Support work is offered as consultations, a standard fixed-price engagement, and individually quoted projects. Starting prices are expressed in Australian dollars. The most common entry point is a technical consultation from A$40 per hour, and fixed-price implementation work is A$100 as a standard rate for a single bounded engagement.

These figures are unrelated to the Website Packages prices. A new website package starts from A$1,000 because it is a build; support work starts from A$40 per hour or A$100 per bounded engagement because it is work on something that already exists. The two are quoted separately, and a fixed-price quote reflects which one is being engaged.

The plan exists because an application that works on a laptop often fails in production for reasons that have nothing to do with the application itself: a build that only works locally, a missing environment variable, an authentication callback pointing at the wrong origin, a database connection that assumes a local socket. Those problems are usually small and bounded, so they suit a fixed-price engagement rather than a long project.

A standard engagement assumes the application is already generally functional. Work that turns out to require major code refactoring, database redesign, large framework migrations, authentication redesign, or significant data migration is identified during the review and quoted separately before any additional work begins.

Services are currently offered in Australia, with all prices in Australian dollars (A$). Remote work for clients outside Australia is planned and will expand in the future — contact me to discuss your location and requirements.
