# How does the Go Support Plan engagement work?

- **Topic:** Support Process
- **Source ID:** support-process
- **URL:** https://www.lst97.dev/services

This document describes the Go Support Plan offering: technical help for a website or application that already exists. It covers the five-stage support engagement. It does not cover the Website Packages offering, which builds a new website from scratch through a separate seven-stage process beginning with project discovery.

The Go Support Plan runs through five stages.

## 1. Consultation or Review

The issue, requirements, or existing application is inspected first. Consultations start from A$40 per hour.

## 2. Diagnosis

The likely cause, the recommended solution, and the implementation requirements are identified.

## 3. Fixed-Price Quote

For straightforward work, a fixed implementation price is provided. Standard implementation work starts from A$100.

## 4. Implementation

Once approved, the required fixes, deployment, migration, or feature work is completed.

## 5. Verification

The completed work is tested against the agreed scope before handover.

Diagnosis is a separate stage from quotation because the price depends on the cause rather than the symptom. A deployment failure can require a configuration change or a structural repair, and those are not the same engagement. The diagnosis stage establishes which one applies before a price is agreed.

Verification is scoped to what was agreed rather than to the application as a whole. Testing is performed against the delivered scope, and anything discovered outside that scope is raised before further work begins rather than absorbed into the existing task.

The sequence is deliberately linear so that cost is known before commitment. No implementation work starts without an approved quote, and no quote is issued before the cause has been established.
