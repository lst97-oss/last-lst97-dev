# What does a technical consultation cover?

- **Topic:** Consultations
- **Source ID:** technical-consultation
- **URL:** https://www.lst97.dev/services

This document describes the Go Support Plan offering: technical help for a website or application that already exists. It covers the hourly consultation, which is the entry point for most support work. It does not cover the Website Packages offering, which builds a new website from scratch starting from A$1,000, and it does not cover the fixed-price implementation engagements, which are quoted separately from the consultation.

Technical consultation is available from A$40 per hour. A consultation is used when the client needs help understanding a situation rather than having it fixed immediately.

Consultation topics include:

- why a website is not deploying
- which hosting platform to use
- whether an application is production-ready
- why a build or runtime error is happening
- how to configure a domain or DNS
- how to connect a database
- how to configure environment variables
- whether an existing architecture should be changed
- what needs to be fixed before launch

After the issue has been reviewed, a separate implementation quote can be provided if development work is required. Consultation and implementation are separate engagements: the consultation establishes what is wrong and what it will take to correct, and the quote is for the corrective work itself.

For larger projects, the consultation fee may be credited toward the implementation cost. For example, a technical consultation at A$40 followed by a A$600 implementation with the consultation credited leaves A$560 remaining. Eligibility for consultation credit is confirmed as part of the quotation.

This arrangement exists so a client is not committed to a development engagement in order to find out what the problem is. A short consultation is often sufficient to identify that a deployment fails purely because of a build configuration issue, which is a bounded fix rather than a project.

A$40 per hour is the only hourly figure in this plan. It is the rate for diagnosing an existing application, and it is not a build rate, a maintenance retainer, or the A$50/hour ongoing maintenance rate that applies to a website built under a package.
