# How much do bug fixes cost?

- **Topic:** Support Engagements
- **Source ID:** support-bug-fixes
- **URL:** https://www.lst97.dev/services

This document describes the Go Support Plan offering: technical help for a website or application that already exists. It covers the Bug Fix engagement. It does not cover the Website Packages offering, which builds a new website from scratch, and the A$100 figure here is a support rate for fixing an existing application rather than a build price.

Bug Fix is a standard A$100 engagement. Small development and production issues can often be handled as fixed-price tasks.

Examples include:

- broken contact forms
- API requests not working
- TypeScript errors
- responsive layout issues
- authentication problems
- image loading issues
- broken routes
- form validation bugs
- production-only errors
- dependency problems

These are handled as fixed-price tasks because they are bounded in a way that a diagnosis is not. A broken contact form has an observable failure, an identifiable cause, and a verifiable fix, which makes it suitable for an agreed price rather than an open-ended hourly engagement.

Responsive layout issues and production-only errors are included because they are among the most common reasons an otherwise finished application is not ready to launch. A layout that breaks on a phone, or an error that appears only in production, is usually a small correction once it has been located.

If a reported bug turns out to be part of a larger structural problem, that is identified during the review and quoted separately rather than absorbed into the original task.
