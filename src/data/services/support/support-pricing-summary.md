# What does technical support cost?

- **Topic:** Pricing
- **Source ID:** support-pricing-summary
- **URL:** https://www.lst97.dev/services

This document describes the Go Support Plan offering: technical help for a website or application that already exists. It covers what support work costs. It does not cover the Website Packages offering, which builds a new website from scratch at different figures, and none of the prices below apply to building a new website.

Technical support pricing, starting from:

| Service | Price |
| --- | --- |
| Technical Consultation | From A$40 / hour |
| Standard support engagement | From A$100 |
| Migration / Major Refactor | Custom Quote |

All prices are starting prices and may vary depending on project complexity. The A$100 figure is the standard rate for a single bounded support engagement, not a per-hour rate.

Third-party hosting, domain, infrastructure, API, SaaS, or subscription costs are not included unless specifically stated in the quotation.

Support work has one standard price of A$100 rather than a ladder of tiers. Deployment, deployment fixes, bug fixes, domain and DNS setup, production readiness review, small feature implementation, CMS and API integration, and database and backend support are all the same kind of engagement: a bounded fix to something that already exists. Charging more for one of them than another implied a difference in difficulty that did not exist.

The A$100 standard covers the agreed scope for that engagement. A larger change is quoted before any work begins rather than absorbing the difference into the standard price.

The consultation rate is the only hourly figure in the plan, and it exists because an open-ended diagnostic cannot be priced in advance. Consultations sit alongside the standard engagement: the consultation establishes what is wrong, and the A$100 engagement carries out the fix. Once the diagnosis is complete the work either becomes a standard engagement or, if the cause is structural, a custom quotation.

Migration and major refactoring have no starting price because the work is defined by the condition of the existing system. Quoting before inspection would be guesswork.

Third-party costs are excluded because they are billed by the provider rather than by the engagement. A standard A$100 engagement does not include the hosting bill for the database it configures.

The A$100 standard support engagement and the A$100 additional revision round offered as a build add-on are different services with the same number. One is a bounded fix to an existing application, the other is an extra revision round on a website being built. They are quoted separately and a visitor asking about an existing site needs the support engagement, not the build add-on.
