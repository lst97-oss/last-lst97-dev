# Walk us through one of your strongest projects.

- **Category:** Introduction and Background
- **Source ID:** strongest-project-walkthrough
- **URL:** https://www.lst97.dev/chat

One of my strongest projects is the system I developed for Best Maker Pty Ltd. I built the system largely from the ground up, which meant I was involved in almost every stage of the project. I had to decide on the technology stack, libraries, architecture, design patterns, colour scheme, database structure, UI/UX, CI/CD pipeline, SEO strategy, and third-party integrations. The system includes technologies and services such as Cloudflare R2, domain and DNS configuration, authentication, Turnstile, Payload CMS, and Medusa for e-commerce. One interesting architectural problem was authentication. I wanted the storefront, Payload CMS, and Medusa services to work together while keeping the user experience consistent, so I designed the authentication flow so that credentials and user information could be shared or coordinated between the different services. The project also taught me that full-stack development is not only about technical implementation. I had to communicate with the client several times to understand what they actually needed and avoid overengineering the solution. Instead of trying to build everything immediately, I provided MVP versions so the client could see and interact with the system. That made it easier to confirm whether the system matched their expectations before investing more development time. I also started separating some functionality into smaller services, such as PDF generation and email delivery. This made the architecture more modular and gives the system more room to scale or change in the future. The system has gradually developed beyond a normal company website and is becoming closer to an ERP-style platform, including quotation management, expense management, automation, and e-commerce functionality. Because of that, I am currently working on evolving the architecture toward a SaaS model so it could eventually support multiple businesses instead of being designed only for one company.
