# What are the main differences between a class component and a function component in React?

- **Category:** Fundamental Questions
- **Source ID:** react-class-vs-function-components
- **URL:** https://www.lst97.dev/chat

Class components were commonly used in React a long time ago. By the time I started learning React, the ecosystem had already largely migrated to function components. I personally have not investigated deeply into why React moved from class components to function components. Based on my current understanding, I believe maintainability is one of the reasons. This is an area I would like to investigate further so I can better understand why function components became the preferred approach.
