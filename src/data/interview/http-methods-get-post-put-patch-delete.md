# Explain the difference between GET, POST, PUT, PATCH, and DELETE.

- **Category:** Fundamental Questions
- **Source ID:** http-methods-get-post-put-patch-delete
- **URL:** https://www.lst97.dev/chat

Based on my understanding, they can basically be related to common database operations:

- GET is used for reading data.
- POST is used for creating data.
- PUT is used for updating a record.
- PATCH is used for updating part of a record, such as specific columns or fields.
- DELETE is used for deleting a record.
