# LAST//OS

LAST//OS is a personal portfolio and publishing site presented as a desktop-like operating system. Its editorial content is authored in Payload and presented through the public site.

## Content language

**Post**: An editorial note or article. Tags describe its subject; publication status determines whether it is available to public readers.

**Project**: A portfolio record describing work, technologies, links, and (when useful) the operator's role and delivery timeframe.

**Publication status**: Editorial visibility of a post or project (`draft` or `published`). It controls public availability and is separate from the work's progress.

**Project lifecycle**: The delivery state of a project (`planned`, `in progress`, `completed`, or `archived`). It describes the work itself and does not control whether the project is publicly visible.

**Changelog**: A release note describing what shipped, changed, or was fixed. Version labels the release (e.g. `v1.4.0`); tags describe the change; publication status determines whether it is available to public readers.

**SEO overrides**: Optional per-content title, description, and social image. When an override is absent, public metadata uses the content's title, excerpt or summary, and cover image.
